# Netradhrishti Architecture

Netradhrishti is built as a multi-module cybersecurity platform.

## Module 1 (Current)
- Foundation
- Schemas (Event, Signal, Incident, Entity)
- Basic Pipeline (Ingest, Validate, Store)

## Future Modules
- Module 2: Data Ingestion & Connector Framework
- Module 3: Event Normalization & Entity Resolution
- Module 4: Suspicious Activity Detection Engine
- Module 5: Event Correlation Engine
- Module 6: Threat Intelligence Engine
- Module 7: Attack Graph & Risk Engine
- Module 8: AI Incident Analysis Engine
- Module 9: Response, Mitigation & Prevention Engine
- Module 10: Dashboard, API & Production Integration
